# Contract: Service Worker

**Feature**: 010-pwa-conversion  
**Type**: Service Worker Lifecycle & Caching API  
**Date**: October 24, 2025

## Overview

This contract defines the service worker behavior, lifecycle events, caching strategies, and communication protocol between the service worker and clients. The service worker is generated by Workbox via `next-pwa` and handles offline functionality, caching, and push notifications.

---

## Service Worker Registration

### Client-Side Registration

**Location**: `src/app/layout.tsx` (Client Component)

**Implementation**:
```javascript
'use client';

import { useEffect } from 'react';

export function PWARegistration() {
  useEffect(() => {
    if (
      typeof window !== 'undefined' &&
      'serviceWorker' in navigator &&
      process.env.NODE_ENV === 'production'
    ) {
      navigator.serviceWorker
        .register('/sw.js')
        .then(registration => {
          console.log('[PWA] Service Worker registered:', registration.scope);
          
          // Listen for updates
          registration.addEventListener('updatefound', () => {
            const newWorker = registration.installing;
            newWorker?.addEventListener('statechange', () => {
              if (newWorker.state === 'installed' && navigator.serviceWorker.controller) {
                // New version available
                window.dispatchEvent(new CustomEvent('sw-update-available'));
              }
            });
          });
        })
        .catch(error => {
          console.error('[PWA] Service Worker registration failed:', error);
        });
    }
  }, []);

  return null;
}
```

**Contract**:
- ✅ Service worker MUST be registered only in production (`process.env.NODE_ENV === 'production'`)
- ✅ Service worker MUST be located at `/sw.js` (root scope for all pages)
- ✅ Registration MUST handle errors gracefully (catch block logs error, does not throw)
- ✅ Update detection MUST dispatch `sw-update-available` custom event to notify UI

## Lifecycle Events

### Install Event

**Purpose**: Precache critical app resources on service worker install

**Behavior**:
```javascript
// Generated by Workbox in /public/sw.js
self.addEventListener('install', event => {
  event.waitUntil(
    (async () => {
      // Precache app shell
      const cache = await caches.open('app-shell-v1');
      await cache.addAll([
        '/',
        '/entries',
        '/settings',
        '/offline.html',
        '/icons/icon-192x192.png',
        '/icons/icon-512x512.png'
      ]);
      
      // Skip waiting to activate immediately
      await self.skipWaiting();
    })()
  );
});
```

**Contract**:
- ✅ Install event MUST precache critical app shell resources
- ✅ Install event MUST call `self.skipWaiting()` to activate new version immediately
- ✅ Cache name MUST include version (`app-shell-v1`) for invalidation
- ✅ Precache list MUST include offline fallback page (`/offline.html`)

---

### Activate Event

**Purpose**: Clean up old caches and claim clients

**Behavior**:
```javascript
self.addEventListener('activate', event => {
  event.waitUntil(
    (async () => {
      // Delete old cache versions
      const cacheAllowlist = ['app-shell-v1', 'api-entries-v1', 'api-settings-v1', 'images-v1', 'google-fonts'];
      const cacheNames = await caches.keys();
      
      await Promise.all(
        cacheNames.map(cacheName => {
          if (!cacheAllowlist.includes(cacheName)) {
            console.log('[PWA] Deleting old cache:', cacheName);
            return caches.delete(cacheName);
          }
        })
      );
      
      // Claim all clients immediately
      await self.clients.claim();
    })()
  );
});
```

**Contract**:
- ✅ Activate event MUST delete old cache versions not in allowlist
- ✅ Activate event MUST call `self.clients.claim()` to control existing pages
- ✅ Cache allowlist MUST be updated when cache names change
- ✅ Cache deletion MUST log to console for debugging

---

### Fetch Event

**Purpose**: Intercept network requests and apply caching strategies

**Behavior**:
```javascript
self.addEventListener('fetch', event => {
  const { request } = event;
  const url = new URL(request.url);
  
  // Determine strategy based on URL
  if (url.pathname.startsWith('/api/entries')) {
    event.respondWith(networkFirstStrategy(request));
  } else if (url.pathname.startsWith('/api/settings')) {
    event.respondWith(staleWhileRevalidateStrategy(request));
  } else if (url.pathname.endsWith('.png') || url.pathname.endsWith('.jpg')) {
    event.respondWith(cacheFirstStrategy(request));
  } else {
    event.respondWith(cacheFirstStrategy(request));
  }
});
```

**Contract**:
- ✅ Fetch event MUST intercept all same-origin requests
- ✅ Strategy selection MUST be based on URL pattern
- ✅ Failed fetch MUST fall back to offline.html for navigation requests
- ✅ Fetch errors MUST NOT crash service worker (catch blocks required)

## Caching Strategies

### Cache-First (Static Assets)

**Use Case**: App shell (HTML, CSS, JS), images, fonts

**Flow**:
```
1. Check cache
   ├─ Found → Return cached response
   └─ Not found → Fetch from network
      ├─ Success → Cache response + Return
      └─ Fail → Return offline.html (if navigation)
```

**Implementation**:
```javascript
async function cacheFirstStrategy(request) {
  const cache = await caches.open('app-shell-v1');
  const cached = await cache.match(request);
  
  if (cached) {
    return cached;
  }
  
  try {
    const response = await fetch(request);
    if (response.ok) {
      cache.put(request, response.clone());
    }
    return response;
  } catch (error) {
    // Return offline fallback for navigation requests
    if (request.mode === 'navigate') {
      return cache.match('/offline.html');
    }
    throw error;
  }
}
```

**Contract**:
- ✅ Cache match MUST be checked before network request
- ✅ Only 200 OK responses MUST be cached
- ✅ Response MUST be cloned before caching (streams can only be read once)
- ✅ Navigation requests MUST fall back to `/offline.html` on network failure

---

### Network-First (API Data)

**Use Case**: `/api/entries` (fresh data preferred, cache as fallback)

**Flow**:
```
1. Fetch from network (10s timeout)
   ├─ Success → Cache response + Return
   └─ Fail/Timeout → Check cache
      ├─ Found → Return cached response
      └─ Not found → Throw error
```

**Implementation**:
```javascript
async function networkFirstStrategy(request, cacheName = 'api-entries-v1', timeout = 10000) {
  const cache = await caches.open(cacheName);
  
  try {
    const networkResponsePromise = fetch(request);
    const timeoutPromise = new Promise((_, reject) => 
      setTimeout(() => reject(new Error('Network timeout')), timeout)
    );
    
    const response = await Promise.race([networkResponsePromise, timeoutPromise]);
    
    if (response.ok) {
      cache.put(request, response.clone());
    }
    
    return response;
  } catch (error) {
    console.log('[PWA] Network failed, checking cache:', error.message);
    const cached = await cache.match(request);
    
    if (cached) {
      return cached;
    }
    
    // No cache available, return error response
    return new Response(
      JSON.stringify({ error: 'Offline and no cached data available' }),
      {
        status: 503,
        statusText: 'Service Unavailable',
        headers: { 'Content-Type': 'application/json' }
      }
    );
  }
}
```

**Contract**:
- ✅ Network request MUST have timeout (10s default)
- ✅ Successful responses (200 OK) MUST be cached
- ✅ Cache MUST be checked on network failure
- ✅ No cache available MUST return 503 Service Unavailable

---

### Stale-While-Revalidate (Settings)

**Use Case**: `/api/settings` (show cached, update in background)

**Flow**:
```
1. Return cached response immediately (if available)
2. Fetch from network in background
   └─ Success → Update cache
```

**Implementation**:
```javascript
async function staleWhileRevalidateStrategy(request, cacheName = 'api-settings-v1') {
  const cache = await caches.open(cacheName);
  const cached = await cache.match(request);
  
  // Fetch in background (don't await)
  const fetchPromise = fetch(request).then(response => {
    if (response.ok) {
      cache.put(request, response.clone());
    }
    return response;
  });
  
  // Return cached immediately, or wait for network
  return cached || fetchPromise;
}
```

**Contract**:
- ✅ Cached response MUST be returned immediately if available
- ✅ Network fetch MUST happen in background (no await)
- ✅ Cache MUST be updated on successful network response
- ✅ If no cache exists, MUST wait for network response

## Message Passing

### Client → Service Worker

**Use Case**: Trigger sync, skip waiting, clear cache

**Protocol**:
```javascript
// Client code
const registration = await navigator.serviceWorker.ready;
registration.active.postMessage({
  type: 'SKIP_WAITING'
});

registration.active.postMessage({
  type: 'SYNC_NOW'
});
```

**Service Worker Handler**:
```javascript
self.addEventListener('message', event => {
  switch (event.data.type) {
    case 'SKIP_WAITING':
      self.skipWaiting();
      break;
      
    case 'SYNC_NOW':
      // Trigger Background Sync
      event.waitUntil(processSyncQueue());
      break;
      
    case 'CLEAR_CACHE':
      event.waitUntil(
        caches.keys().then(names => 
          Promise.all(names.map(name => caches.delete(name)))
        )
      );
      break;
      
    default:
      console.warn('[PWA] Unknown message type:', event.data.type);
  }
});
```

**Contract**:
- ✅ Message types MUST be uppercase strings (e.g., `'SKIP_WAITING'`)
- ✅ Service worker MUST handle unknown message types gracefully
- ✅ Async operations MUST use `event.waitUntil()` to extend event lifetime
- ✅ Message responses MUST be sent via `event.ports[0].postMessage()` if reply needed

---

### Service Worker → Client

**Use Case**: Notify client of cache update, sync status

**Protocol**:
```javascript
// Service worker code
const clients = await self.clients.matchAll({ type: 'window' });
clients.forEach(client => {
  client.postMessage({
    type: 'CACHE_UPDATED',
    payload: { cacheName: 'api-entries-v1', url: request.url }
  });
});
```

**Client Handler**:
```javascript
// Client code
navigator.serviceWorker.addEventListener('message', event => {
  switch (event.data.type) {
    case 'CACHE_UPDATED':
      console.log('[PWA] Cache updated:', event.data.payload);
      break;
      
    case 'SYNC_STATUS':
      updateSyncIndicator(event.data.payload);
      break;
      
    default:
      console.warn('[PWA] Unknown message from SW:', event.data.type);
  }
});
```

**Contract**:
- ✅ Client messaging MUST use `self.clients.matchAll()` to find targets
- ✅ Message payload MUST be JSON-serializable
- ✅ Client MUST register message listener before SW is active
- ✅ Unknown message types MUST be logged, not throw errors

## Update Flow

### Detecting Updates

**Trigger**: New service worker version deployed

**Flow**:
```
1. User visits site
2. Browser checks /sw.js for updates
3. New SW found → Install new SW in background
4. New SW enters 'installed' state
5. Dispatch 'sw-update-available' event
6. Show UpdateBanner component to user
7. User clicks "Reload" → Call skipWaiting() → New SW activates
```

**Client Implementation**:
```javascript
// UpdateBanner.jsx
export function UpdateBanner() {
  const [showUpdate, setShowUpdate] = useState(false);
  
  useEffect(() => {
    const handleUpdate = () => setShowUpdate(true);
    window.addEventListener('sw-update-available', handleUpdate);
    return () => window.removeEventListener('sw-update-available', handleUpdate);
  }, []);
  
  const handleReload = async () => {
    const registration = await navigator.serviceWorker.ready;
    registration.waiting?.postMessage({ type: 'SKIP_WAITING' });
    window.location.reload();
  };
  
  if (!showUpdate) return null;
  
  return (
    <div className="update-banner">
      <p>A new version is available!</p>
      <button onClick={handleReload}>Reload</button>
    </div>
  );
}
```

**Contract**:
- ✅ Update detection MUST be non-blocking (background)
- ✅ User MUST be notified of available update (via UI banner)
- ✅ User MUST explicitly trigger update (click "Reload")
- ✅ `skipWaiting()` MUST be called before page reload

## Push Notification Handling

### Push Event

**Trigger**: Server sends push notification via Web Push Protocol

**Service Worker Handler**:
```javascript
self.addEventListener('push', event => {
  const data = event.data ? event.data.json() : {};
  
  const title = data.title || 'Fasting Tracker';
  const options = {
    body: data.body,
    icon: data.icon || '/icons/icon-192x192.png',
    badge: data.badge || '/icons/badge-72x72.png',
    tag: data.tag || 'default',
    data: data.data || {},
    vibrate: [200, 100, 200],
    requireInteraction: false
  };
  
  event.waitUntil(
    self.registration.showNotification(title, options)
  );
});
```

**Contract**:
- ✅ Push event MUST parse `event.data` as JSON
- ✅ Notification MUST be shown via `showNotification()` (required for userVisibleOnly)
- ✅ Notification options MUST include icon, badge, tag, data
- ✅ `event.waitUntil()` MUST be called to keep SW alive during notification

### Notification Click

**Trigger**: User clicks on push notification

**Service Worker Handler**:
```javascript
self.addEventListener('notificationclick', event => {
  event.notification.close();
  
  const url = event.notification.data.url || '/entries';
  
  event.waitUntil(
    clients.matchAll({ type: 'window', includeUncontrolled: true })
      .then(clientList => {
        // Focus existing window if open
        for (const client of clientList) {
          if (client.url === url && 'focus' in client) {
            return client.focus();
          }
        }
        
        // Open new window
        if (clients.openWindow) {
          return clients.openWindow(url);
        }
      })
  );
});
```

**Contract**:
- ✅ Notification MUST be closed on click (`event.notification.close()`)
- ✅ Existing window MUST be focused if already open
- ✅ New window MUST be opened if no existing window
- ✅ Deep link URL MUST be extracted from `event.notification.data.url`

## Error Handling

### Network Errors

**Contract**:
- ✅ Network errors MUST NOT crash service worker
- ✅ Network errors MUST log to console for debugging
- ✅ Network errors MUST return cached response or offline fallback
- ✅ Critical errors MUST be sent to server via `/api/pwa/log-error`

**Implementation**:
```javascript
async function safeFetch(request) {
  try {
    const response = await fetch(request);
    return response;
  } catch (error) {
    console.error('[PWA] Fetch failed:', request.url, error);
    
    // Log critical errors
    if (request.url.includes('/api/')) {
      logError('fetch-failed', error.message, { url: request.url });
    }
    
    // Return cached or offline fallback
    const cache = await caches.open('app-shell-v1');
    return cache.match(request) || cache.match('/offline.html');
  }
}
```
